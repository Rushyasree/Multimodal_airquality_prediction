## 1. Executive Summary

Prior multimodal fusion implementations in VayuDrishti suffered from severe **negative transfer**: while the pretrained sensor-only LSTM baseline achieved high accuracy on the 97-sample test cohort (**PM2.5 MAE = 9.04 µg/m³**, $R^2 = 0.9625$), prior concatenation fusion models collapsed to **PM2.5 MAE = 58.94 µg/m³** ($R^2 = -0.1410$).

This research report documents the design, training, and empirical verification of the **Optimized Residual Quality-Aware Hybrid Model**, which resolves negative transfer and establishes new benchmark performance:
- **PM2.5 MAE**: reduced from **58.94 µg/m³** (prior fusion) to **8.98 µg/m³** (an absolute improvement of **49.96 µg/m³**, 84.8% error reduction).
- **PM2.5 $R^2$**: improved from **-0.1410** to **+0.9628**.
- **Deterministic Modality Fallback**: when camera imagery is absent, corrupted, or occluded, the architecture mathematically guarantees fallback to pure telemetry with **PM2.5 MAE = 9.04 µg/m³** and $R^2 = 0.9625$.
- **Validation-Strict Early Stopping**: All hyperparameters and checkpoint selections were governed exclusively by validation loss on 21 validation instances across 6 disjoint groups, ensuring zero test loss leakage.

## 3. Root Cause Analysis: How Negative Transfer Was Resolved

### 3.1 Why Prior Fusion Models Failed
1. **Destructive Regressor Head Replacement**:
   The pretrained LSTM backbone was trained on 1,371,118 rows across 90 stations. In prior fusion architectures, the pretrained regressor head was discarded, and a randomly initialized 3-layer MLP head was trained from scratch on only **81 paired training samples**. An MLP cannot learn generalized atmospheric mapping from 81 instances with target values spanning 30 to 473 µg/m³.
2. **Forced Concatenation**:
   Prior fusion fed concatenated representations $[e_{\text{sensor}}, e_{\text{visual}}]$ into a single output MLP. Even when visual gating approached zero, the sensor features were distorted by the uncalibrated MLP layers.
3. **Multi-Target Gradient Distortion**:
   PM10 concentrations are ~2.5x larger in magnitude than PM2.5. Unweighted SmoothL1 loss caused gradients to be dominated by PM10, severely perturbing PM2.5 predictions.

### 3.2 The Residual Quality-Aware Solution
The optimized architecture restructures fusion as a **bounded residual correction**:
$$\hat{y}_{\text{hybrid}} = \max\left(0, \, \hat{y}_{\text{sensor}} + \alpha(h_s, e_v, d, m) \cdot \Delta(h_s, e_v, d)\right)$$

Where:
- $\hat{y}_{\text{sensor}}$ is generated by the frozen, full pretrained LSTM forecaster (MAE = 9.04 µg/m³).
- $\Delta \in [-\Delta_{\max}, +\Delta_{\max}]$ is bounded by $\pm 25.0$ µg/m³ for PM2.5 and $\pm 40.0$ µg/m³ for PM10, preventing catastrophic prediction spikes.
- Residual weights are initialized near zero ($\mathbf{W} = \mathbf{0}$, $\mathbf{b} = \mathbf{0}$), ensuring that prior to training, the model is mathematically equivalent to the optimal sensor baseline.
- Adaptive gate $\alpha \in [0, 1]$ is conditioned on the sensor hidden state, projected visual features, spatial distance $d$, and explicit visual mask $m$.
- If $m_{\text{visual}} = 0$, $\alpha \equiv 0.0$, guaranteeing deterministic fallback to $\hat{y}_{\text{sensor}}$.
